The original car, built at Fremont from July 2017 and later at Shanghai
too.[@wikipedia-tesla-model-3]

Two things about the numbers below are worth knowing before you read them.

Tesla publishes no power figure for any Model 3, so every output here comes
from a regulator. For the rear-drive car that is the EPA, which records the
motor rating. For the dual-motor car the EPA is no help — it rates the two
motors separately, and a front and a rear rating cannot be added into a system
output — so the figure comes from Natural Resources Canada, which publishes a
single combined output in kilowatts.[@nrcan-fcr-bev-2012-2026]

And every acceleration claim Tesla makes is a 0–60 mph time, which is not the
0–100 km/h time this site records, so those cells are empty rather than
approximated.
