The Urus has been a single, continuously updated generation since 2017 —
Lamborghini's naming has moved through Urus, Urus S, Urus Performante and now
Urus SE without ever calling any of them a new generation, so this entry
follows that and treats the run as one, with the launch car and the current
SE as its two bracketing trims.[@wikipedia-lamborghini-urus]

The SE's power and torque figures are Lamborghini's own published system
totals for the plug-in hybrid V8-plus-motor combination — 596 kW and 950 N⋅m —
which do not equal the sum of the 462 kW/800 N⋅m engine and 141 kW/483 N⋅m
motor figures also quoted in the same article, because engine and motor peak
at different points and cannot be added together. Only the manufacturer's own
combined figures are recorded.

The SE's mass is left as a gap rather than a guess. The article states it is
"roughly 300 kg" heavier than the Urus S, but the Urus S's own kerb weight is
never independently given — only the original 2017 Urus's 2,200 kg is, which
NHTSA's Canadian Vehicle Specifications register independently confirms for
the 2019 model year. Adding an approximate delta to a different car's weight
would be an invented number wearing a `verified` label, so the SE's mass is
recorded as a placeholder instead.
